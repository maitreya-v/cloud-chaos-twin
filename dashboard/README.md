# Dashboard · Mithil with Maitreya

The starter generates an offline HTML report through `python3 -m cct demo`. It uses synthetic data and is not a running or hosted dashboard.

After the real pipeline works, add a Streamlit/Plotly interface with run selection, workload/fault interval, service health timeline, observed graph, predicted future impact, and evaluation tables. Always show data source, missing coverage, prediction cutoff, and whether the result is live or replayed. Read compact processed results instead of loading full raw telemetry into the UI.
