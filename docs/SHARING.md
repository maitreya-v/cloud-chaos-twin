# Sharing and collaboration

Team home: https://github.com/maitreya-v/cloud-chaos-twin

The repository was public when initial setup began. Anyone with the link can read public repository files. GitHub write access is separate: the repository owner can invite the four teammates through Settings -> Collaborators using their exact GitHub usernames. An invitation must be accepted before that teammate has access. No collaborator invitations are included in this starter setup.

Teammates should start with README.md, docs/SETUP.md, and docs/TEAM_TASKS.md. Use branches and pull requests for changes. Use issues for blockers and link them from the task board. The repository contains a Markdown task board, not a separately configured GitHub Projects board.

The repository stores source/configuration/documentation and small synthetic examples. It does not host a live dashboard or running cluster. The generated demo report runs locally; real telemetry should use separate controlled storage with an index in the repository.

The shared Boutique runs separately on Maitreya's Mac. See [private access](PRIVATE_ACCESS.md) for the private website, Kubernetes access design, activation status, and teammate checks. GitHub access and private-network membership are separate.

If changing repository visibility later, check the team's access and course requirements first. Do not upload the source proposal with student IDs to the public repository.
